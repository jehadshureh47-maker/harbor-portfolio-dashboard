Data Quality Validator

Standalone tool · flags likely data-entry issues before a report reaches the dashboard · does not modify the Dashboard or any existing files

1. Choose portfolio & report type

Pick the portfolio first, same as the Dashboard, the report type dropdown then only shows that portfolio's reports. Each report type has a different column layout and different checks that make sense for it. Uploading a file in step 2 auto-detects both from its filename and columns, you only need to touch these if you want to look at a config before uploading, or if the auto-detect gets it wrong.

2. Upload a report to check

Reads the "Details" sheet if present, otherwise the first sheet. If this is the full monthly Al Naser workbook (several report sheets in one file), pick the report type in step 1 first so the right sheet gets read.
